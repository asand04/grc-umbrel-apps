# GR Créations — Umbrel community app store

Ajoutez `https://github.com/asand04/grc-umbrel-apps` dans umbrelOS (App Store → ⋯ → Community App Stores) pour installer **GR Commandes**, l'application de suivi des commandes, devis et factures de GR Créations (impression 3D, Cotonou).

Ce dépôt ne contient que les manifestes Umbrel. Il est régénéré par `app/scripts/release-umbrel.sh` depuis le dépôt principal.
